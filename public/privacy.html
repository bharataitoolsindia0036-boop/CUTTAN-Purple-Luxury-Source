CUTTAN Privacy Notice

Draft for review · updated 25 October 2026

This notice describes the supplied source build and must be reviewed against the actual published app and hosting setup before release.

Media processing

The app reads video and audio selected by you in your browser and uses a bundled FFmpeg WebAssembly engine to process export locally. The source includes no media-upload endpoint, account system, analytics SDK or advertising SDK. Exported files are downloaded to your device.

Projects and storage

Recent project names are stored in browser localStorage. Exported project JSON files contain editing settings and project name, not the original media. You must reselect the source media when reopening a project.

Network and hosting

Hosting providers may process ordinary web request metadata. This app must not be described as completely offline until offline operation is implemented and tested on the final build.

Contact

Before publication, replace this draft with your real support contact and legal/business details, and provide a process for privacy requests. Update this notice if the final app adds analytics, ads, accounts, cloud sync, payments or other data collection.
